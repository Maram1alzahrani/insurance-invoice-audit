# AI Prompt History

AI assistance was used throughout this exercise, as permitted by the task.
The interaction was iterative and conversational rather than a sequence of
single, fixed prompts. The files in this directory preserve the main prompt
versions, changes in direction, and resulting decisions.

The wording has been condensed from the working conversation for readability;
the technical intent, constraints, and iteration history are preserved. AI
output was not accepted blindly: generated code was run locally, results were
compared with the Hospital 1 labels, low-confidence cases were reviewed, and
changes were regression-tested across Hospitals 1, 3, and 4.

Files:

1. `01_baseline_v1.md` — initial data checks and baseline audit.
2. `02_contract_rules_v2.md` — contract parsing and rule-engine expansion.
3. `03_hospital_3_v3.md` — multi-document contract and effective-date logic.
4. `04_hospital_4_submission_v4.md` — second unlabelled hospital, review, and submission validation.
